🔑 GitHub 저장 권한 설정

GitHub에 데이터를 직접 저장하려면 Personal Access Token(PAT)이 필요합니다.
설정 방법: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
권한: Contents → Read and write (GSMM repository만 선택)

※ 토큰은 이 기기의 브라우저에만 저장되며 외부로 전송되지 않습니다.
